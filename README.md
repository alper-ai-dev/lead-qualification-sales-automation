# Pulse — Lead Qualification & Sales Automation

A working portfolio demo for inbound lead qualification, scoring and CRM-style sales routing.

## What it demonstrates
- Structured inbound lead capture
- Deterministic lead scoring
- Company-fit and buying-intent signals
- Hot / warm / cold qualification
- Priority and next-best-action rules
- CRM-style pipeline routing
- Responsive sales operations UI

## Scoring model
The public demo calculates a transparent score from company size, stated budget, purchase timeline, decision role and intent keywords in the prospect request. It does not pretend to use AI or a third-party CRM API.

## Pipeline
Qualified leads can be routed into the on-page sales pipeline. The portfolio version keeps the workflow in the browser and is intentionally credential-free so recruiters can test it instantly.

## Stack
HTML5, CSS3, Vanilla JavaScript.

## Production extension
The same interface can be connected to a real CRM, webhook endpoint, database, workflow automation platform or LLM-based classifier when production credentials and business rules are available.
